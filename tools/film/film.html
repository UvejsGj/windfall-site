Windfall

How the phone page gets files between an iPhone and Windows
Ordinary Wi-Fi · no app · no extra hardware
01 · The problem

AirDrop needs a radio mode Windows can't drive.

An iPhone only AirDrops over AWDL, Apple's second Wi-Fi link layer. Windows exposes no way to run it.

01 · The way round

So use the Wi-Fi both devices already share.

Windfall serves a small web page on the local network. It is not AirDrop, and it needs no Linux, no app on the phone and no extra hardware.

02 · Scan

The PC shows a code. The iPhone's camera reads it.

The code holds the PC's address and a secret token: 128 random bits, new every run. Safari opens the page. Any request without the token gets a 404.

03 · Send, in order

The phone sends the list first, then the files.

One POST /<token>/upload. The form fields arrive in a fixed order, and the order is the point.

04 · Ask before reading

The PC asks before it reads a single byte of a file.

The list is what the person sees. Until they answer, the upload waits in the socket and TCP holds the phone back, so nobody can push a file onto the PC unasked.

04 · Accepted

Accept, and the bytes flow at Wi-Fi speed.

Files are staged, then committed all or nothing. Five photos, 3.6 MB together, arrived intact from a real iPhone.

05 · The list is binding

What was agreed to is what lands on disk.

Each file is saved under the name the list gave it and may be no larger than the list said. Any mismatch fails the whole upload.

06 · Decline

Say no, and the phone hears it.

The refusal goes out while the phone is still uploading. Safari shows "Declined on" the PC's name, and nothing is left behind: no file, no staging folder.

07 · The other way

The PC can offer files back to the phone.

Only while the phone sheet is open. Each offer has a generation number, so an old link stops working the moment the offer changes. Downloads land in the Files app.

08 · Security model

Two locks, and plain HTTP on purpose.

Safari shows a full-page warning for a self-signed certificate. Rather than teach people to click through it, the page relies on the token, the prompt and the Wi-Fi's own encryption.

09 · Verified

Tested with a real iPhone on iOS 27.0.1.

The Windfall app on plain Windows, over home Wi-Fi.

The prompt

Anyone with the link can ask to send files. Nothing is written until the person at the PC agrees. New link takes the address back.

ProtectedFrom outsiders, by the Wi-Fi's encryption. From others on the network without the link, by the token.
Not protectedFrom someone on the same network who can intercept traffic. So: home and other trusted networks.
