# windfall-site

The website for [Windfall](https://github.com/UvejsGj/Windfall), an AirDrop implementation
for Windows and Linux, built from scratch by reverse-engineering the protocol.

Live at <https://uvejsgj.github.io/windfall-site/>.

## How it works

GitHub Pages serves the files from the root of `main` as they are, so a push to `main`
updates the site within a minute or two. Nothing is built on GitHub.

| File | What it is |
|---|---|
| `index.html` | The home page |
| `notes.html` | The lab notes. Generated by `tools/build_notes.py`, so do not edit it by hand |
| `site.css` | The styles for both pages |
| `site.js` | The motion and the list of entries on the notes page. Both pages read in full without it |
| `tools/build_notes.py` | Builds `notes.html` from Windfall's `docs/protocol-notes.md` |
| `social-card.png` | The image shown when a link to the site is shared |
| `.nojekyll` | Tells GitHub Pages to serve the files as they are |

To look at a change before pushing it, serve the folder and open it in a browser:

```
python -m http.server 8000
```

## Refreshing the lab notes

The notes are written in the Windfall repository. After they change there, rebuild the page
here and push it:

```
python tools/build_notes.py
```

That takes the notes from Windfall's `main` branch. To build from a local copy instead,
pass its path: `python tools/build_notes.py path/to/protocol-notes.md`.

The script needs only Python and a network connection. GitHub's Markdown service does the
conversion, so the notes read here as they do on GitHub. The script then labels each dated
entry, builds the list of entries, and takes the page frame from `index.html`.

## Keeping it true

The home page repeats figures from the Windfall README: the test count, the iOS versions,
how often transfers complete, and the speed. When those change there, change them here too.

## Motion

Every animation is an extra. With scripts off, or when the reader's device asks for reduced
motion, nothing is hidden and nothing moves.
